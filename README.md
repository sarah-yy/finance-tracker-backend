# finance-tracker-backend
Repo housing the backend code for my personal Finance Tracker app

## Requirements
- Node.js v20 and above (you can change the version using [NVM](https://tecadmin.net/install-nvm-macos-with-homebrew/) or [Homebrew](https://www.denisbouquet.com/change-node-version-using-homebrew/))

## Setting up local server

1. On the command line, run `cd /path/to/finance-tracker-backend` to go to the root folder of the project.
2. Run `npm install --force` or `yarn` to install dependencies.
3. Run `yarn build` to compile the code.
4. Run `yarn run:init` to initialise the required databases.
5. Run `yarn dev` to start the localhost server.
